# منصة التقرير الأكاديمي والتعليمي السلوكي | مدارس الأندلس الأهلية

منظومة تقنية معتمدة لقياس وتقويم الأداء الأكاديمي والتعليمي السلوكي لطلاب مدارس الأندلس الأهلية (مكة المكرمة - المرحلة الابتدائية - بنين).

## مميزات المنصة
1. **بوابة موحدة بمسارين مستقلين:**
   - **بوابة المعلمين والإشراف:** رصد درجات الـ 30 معياراً (6 مقررات × 5 عناصر تقييم)، وحساب المجموع التراكمي من 150 نقطة والمعدل من 5.0 تلقائياً.
   - **بوابة ولي الأمر:** استعلام فوري برقم هوية الطالب مع عرض التقرير المعتمد والرسم البياني وملاحظات الموجه الطلابي.
2. **الخطة العلاجية الفورية:**
   - استمارة متابعة وتدخل علاجي للطلاب منخفضي المستوى وفق معايير الاعتماد المدرسي وجودة التعليم.
3. **التوافق التام مع الطباعة (A4 Print-Ready):**
   - إمكانية طباعة وتصدير التقرير الرسمي كملف PDF معتمد بتوقيع الموجه الطلابي ومدير المدرسة بضغطة زر واحدة.

## التقنيات المستخدمة
- HTML5 / Vanilla JavaScript
- Tailwind CSS
- Lucide Icons
- Chart.js
- Vercel Hosting
